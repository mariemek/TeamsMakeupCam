# 💄 TeamsMakeupCam

Real-time virtual makeup for your Mac camera — built with Swift + MediaPipe.

---

## ✨ Features

* 💋 Lipstick & lip liner
* 👁 Eyeliner & lashes
* 👃 Face tracking with MediaPipe
* ⚡ Real-time performance
* 🎥 Works with your Mac camera

---

## 🚀 Download & Install (No Xcode Required)

### ✅ Option 1 — Recommended (DMG Installer)

1. Go to **Releases**:
   👉 https://github.com/mariemek/TeamsMakeupCam/releases

2. Download the latest `.dmg` file

3. Open the `.dmg`

4. Drag **TeamsMakeupCam.app → Applications**

5. Open the app from Applications

---

### ⚠️ First Time Opening

macOS may block the app (because it’s not signed yet):

1. Go to **System Settings → Privacy & Security**
2. Scroll down
3. Click **“Open Anyway”**
4. Confirm

---

## 🎥 Camera Permission

When you open the app:

* macOS will ask for camera access
* Click **Allow**

If you missed it:

👉 System Settings → Privacy & Security → Camera → enable TeamsMakeupCam

---

## 🧠 How It Works

* The app uses **MediaPipe Face Landmarker**
* A bundled helper runs automatically in the background
* No terminal or setup needed

---

## 🛠 For Developers

### Clone the repo

```bash
git clone https://github.com/mariemek/TeamsMakeupCam.git
cd TeamsMakeupCam/TeamsMakeupCam
```

### Open in Xcode

```bash
open TeamsMakeupCam.xcodeproj
```

### Run

* Select **My Mac**
* Press ▶️
